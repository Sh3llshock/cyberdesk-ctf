# CyberDesk

A fake Kali-style desktop in the browser with four beginner cybersecurity CTF challenges for high-school students: an IDOR on a social app, a hidden admin page found with a directory brute-forcer, game memory editing with a CheatEngine-style scanner, and an exposed camera found with nmap.

Everything is simulated client-side — no real systems are contacted. Open `index.html` in a browser or visit the GitHub Pages link. Desktop login: `Jake` / `Jake123`.

For classroom use only. Use these techniques only on systems you are authorized to test.
